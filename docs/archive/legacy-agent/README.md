# Tài liệu lịch sử từ thư mục agent

Thư mục này lưu 15 tài liệu chuyển từ `agent/`, thuộc các giai đoạn Python/WebSocket, Tauri và Rust/Slint. Nội dung có thể mô tả thiết kế chưa triển khai, trạng thái cũ hoặc mục tiêu chưa được đo kiểm; không dùng làm yêu cầu hiện hành.

## Nơi đọc tài liệu đang dùng

- [AGENTS.md](../../../AGENTS.md): hướng dẫn làm việc trong repository.
- [Kế hoạch triển khai](../../plan/implementation/README.md): các stage rebuild Go/Wails/React và mốc duyệt PoC.
- [Dashboard preview](../../DASHBOARD-PREVIEW.md): workflow của ứng dụng Rust/Slint hiện còn trong mã nguồn.
- [UI design](../../UI-DESIGN.md): bố cục và quy tắc dashboard hiện tại.

## Phân loại bản lưu

| Thư mục | Nội dung |
|---|---|
| `about/` | Hướng dẫn setup, kiến trúc, release cũ và README mẫu |
| `plan/` | Kế hoạch cũ, gồm checklist con trong `plan/task/` |
| `prompts/` | Đặc tả/prompt cũ; sửa tên từ `promts/` |
| `task/` | Checklist foundation lịch sử |

Giữ nội dung và trạng thái checkbox để đối chiếu; chỉ bổ sung nhãn lịch sử và sửa đường dẫn khi di chuyển. Không tiếp tục checklist cũ nếu chưa đối chiếu với kế hoạch đang dùng.

`.agents/skills/` dành cho skill của repository có `SKILL.md`; các tài liệu lưu trữ này không phải skill nên không chuyển vào đó.
